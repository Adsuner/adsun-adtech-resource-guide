# Adsun Advertising Technology Resource Guide

Cross-sector discovery map and neutral Awesome contribution drafts.

## What this repository contains

Independent educational example code and public documentation only. It contains no existing Adsun application source, SDK implementation, account tokens, environment files or production data.

## Quick start

Read AWESOME-DRAFTS.md and follow each target maintainer’s current contribution rules before submitting.

## Integration and limitations

Relevant areas include advertising platforms, adtech, bot monetization and game integration tutorials. Adsun browser SDK examples are Telegram Mini App examples; generic HTML5 support is not asserted. Web Monetization payment standards are not equivalent to display advertising. No mass submissions or indexing guarantees.
